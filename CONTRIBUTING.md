# Contributing

This is a research repository. Contributions should preserve scientific traceability.

Before opening a pull request:

- explain the research, software, or documentation change;
- include or update tests for reusable code;
- state whether results or figures changed;
- identify datasets and configurations used;
- record assumptions and limitations;
- run `make test` and `make lint`.

Use small, focused commits. Do not commit credentials, confidential data, or generated files that can be reproduced.
